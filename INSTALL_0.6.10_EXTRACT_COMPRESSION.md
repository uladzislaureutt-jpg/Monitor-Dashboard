# Monitor 0.6.10 — «Экстракт» для AI-компрессии

Устанавливается поверх версии 0.6.9.

## Что добавлено

- В список режимов AI-компрессии добавлен «Экстракт 60–80%».
- Режим оставляет 20–40% исходного текста и предназначен для короткого, фактологически насыщенного варианта публикации.
- Сохраняется ограничение: не более двух AI-запусков для одной публикации.
- Локальная проверка клиента принимает результат только в диапазоне 60–80% сокращения.

## Серверная часть

Функция Supabase `editorial-compress` уже развёрнута отдельно как версия 7. Она принимает режим `extract`, повторяет попытку при выходе из диапазона и проверяет числа, имена, прямые цитаты и соответствие предложений исходному тексту.

## Установка

1. Распакуйте архив в корень репозитория Monitor Dashboard с заменой файлов.
2. Закоммитьте изменения и запустите обычную сборку Windows через GitHub Actions.
3. Установите собранный пакет поверх предыдущей версии приложения.
