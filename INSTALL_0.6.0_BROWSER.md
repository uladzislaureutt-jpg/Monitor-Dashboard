# Monitor 0.6.0 — установка поверх 0.5.3

Пакет устанавливается в репозиторий **Monitor-Dashboard** поверх рабочей 0.5.3.

1. Загрузить содержимое update ZIP в корень репозитория с заменой файлов.
2. Commit changes.
3. Запустить `Actions → Build Monitor Dashboard Windows x64 → Run workflow`.
4. Скачать новый `monitor-dashboard-windows-x64` и установить поверх текущей версии.

SQLite удалять не нужно. При первом запуске schema 4 автоматически обновится до schema 5.

0.6.0 читает и старые Dashboard Contract 0.1 bundle, и новые 0.2. Старые публикации продолжат работать, но полного текста и структурированных персоналий у них задним числом не появится.
