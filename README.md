# Monitor — 0.5.2

Windows x64 desktop-приложение SEP-Monitor: локальный архив SQLite, поиск, аналитика, GitHub Auto Sync и общая сетевая «Рабочая комната».

## Что нового в 0.5.2

### Source Diversity & Coverage Health

В «Аналитике» появились два слоя из дорожной карты:

- **Разнообразие источников**: число активных источников, доля лидера, доля топ-5, эффективное число источников и индекс разнообразия `100 × (1 − HHI)`;
- **Здоровье покрытия** по последнему production-run: «Стабильно», «Через recovery», «Ограничено», «Требует внимания»;
- низкоуровневые технические ошибки вроде `extraction_failed` не выводятся как headline-метрики Dashboard;
- health-категории взаимоисключающие и суммируются в общее число источников coverage последнего production-run.

### Entity Integrity corrective

Усилена временная локальная эвристика блока «Персоналии»:

- медийные/редакционные конструкции (`Новости`, `Навіны`, `Газета`, `Редакция` и т. п.) больше не считаются людьми;
- кандидаты сверяются с каталогом источников, регионами и локалитетами;
- персоналия должна содержать узнаваемое имя/патроним и встретиться минимум в двух разных публикациях;
- тем самым исправлен false positive типа **«Новости Могилева»**.

Это всё ещё промежуточный слой. Следующий качественный скачок — передавать сущности через `entities.jsonl` из мониторинга, а не извлекать их из заголовков/выдержек в desktop.

## Совместимость

- SQLite schema остаётся **3** — миграция БД не требуется;
- накопленные runs, Auto Sync, Workroom, RU/BE, preview images и архив полностью сохраняются;
- обновление не меняет `.github/workflows`.
