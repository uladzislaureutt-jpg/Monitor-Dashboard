# Monitor — 0.4.2 Bilingual Analytics UI

Windows x64 desktop-приложение для накопления и анализа пакетов Dashboard Data Contract SEP-Monitor.

## 0.4.2

- в верхнем левом углу название сокращено до **«Монитор» / «Манітор»**;
- добавлен полноценный переключатель интерфейса **РУ / БЕЛ**;
- переведены навигация, кнопки, подписи, таблицы, фильтры, поиск, рабочая комната и служебные экраны;
- сами публикации, заголовки, выдержки, источники и классификационные значения не переводятся и отображаются как получены;
- периоды **1 / 7 / 30 / 365 дней / всё время** теперь встроены отдельно в «Динамику», «Темы», «Географию» и «Источники» на Dashboard;
- каждый из этих блоков может иметь собственную глубину времени;
- географическая «Схема» заменена на **пропорциональный treemap**: области, Минск и «Вся Беларусь» занимают площадь пропорционально числу публикаций;
- treemap использует шкалу оттенков красного от бледного до насыщенного;
- системная позиция «Не определено» в географических визуализациях показывается пользователю как **«Вся Беларусь» / «Уся Беларусь»**;
- светло-бежевый фон рабочего пространства сохранён и немного усилен для отделения от белых карточек и заливок графиков.

## Язык

Выбор языка хранится локально на компьютере и восстанавливается при следующем запуске. Переключение не затрагивает содержимое архива и SQLite.

## Auto Sync

Механизм 0.4.1 сохранён: приложение может автоматически догружать новые production-пакеты `dashboard-bundle-social-N` из GitHub Actions и пропускать dry-run.

## База данных

Новой миграции в 0.4.2 нет. Существующая `monitor-dashboard.sqlite3` используется без удаления или пересоздания.

## Сборка

Используйте существующий workflow `Build Monitor Dashboard Windows x64`.
