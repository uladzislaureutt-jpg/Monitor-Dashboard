# Monitor Dashboard — 0.4.1 Presentation + Auto Sync

Windows x64 desktop-приложение для накопления и анализа Dashboard Data Contract bundle-файлов SEP-Monitor.

## Что изменено после 0.4.0

- модуль переименован в **SEP-Monitor**;
- фон рабочей области стал светло-бежевым, чтобы не сливаться с заливками диаграмм;
- динамика публикаций теперь показывается **столбцами + линией среднего**;
- для тем и источников можно переключать **столбцы / сектора**;
- для географии доступны **столбцы / сектора / карта-схема Беларуси**;
- «Команда» заменена на **Рабочую комнату** и перенесена в левую панель отдельным тёплым цветом;
- добавлен **Auto Sync** из GitHub Actions artifacts;
- Auto Sync проверяет новые `dashboard-bundle-social-N`, импортирует пропущенные production runs и пропускает dry-run;
- dry-run, уже определённые Auto Sync, запоминаются в SQLite и повторно не скачиваются;
- ручной импорт сохранён как резервный способ.

## Auto Sync

Настраивается в `Данные → Auto Sync · GitHub Actions`.

Нужно указать:

- репозиторий в формате `owner/repository`;
- для приватного репозитория — fine-grained GitHub token с **read-only Actions**;
- интервал 15 / 30 / 60 минут;
- включить «Автоматически».

Проверка выполняется при запуске приложения и затем по выбранному интервалу. При выключенном интернете приложение продолжает работать с локальной SQLite.

### Ограничение 0.4.1

GitHub token пока хранится локально в WebView localStorage этого компьютера. Он не записывается в архив публикаций и не передаётся другим пользователям, но это ещё не финальная схема. После подключения общего backend для «Рабочей комнаты» GitHub-токены у рядовых пользователей можно будет убрать полностью.

## База данных

0.4.1 добавляет миграцию `0002_sync.sql` с технической таблицей уже проверенных dry-run. Существующая `monitor-dashboard.sqlite3` обновляется автоматически; публикации и импортированные runs не удаляются.
