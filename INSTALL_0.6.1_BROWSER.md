# Monitor 0.6.1 — установка через браузер GitHub

Пакет устанавливается поверх рабочей 0.6.0 с cumulative persistence/UI fixes.

1. Откройте репозиторий `Monitor-Dashboard`.
2. Загрузите содержимое `Monitor-0.6.1-update.zip` в корень репозитория с заменой существующих файлов.
3. Создайте commit.
4. Откройте **Actions → Build Monitor Dashboard Windows x64 → Run workflow**.
5. Скачайте новый installer `monitor-dashboard-windows-x64` и установите поверх текущей версии.

SQLite удалять не нужно. Новая миграция не требуется: Report Workspace использует уже существующее постоянное хранилище `app_settings` (schema 6).

### Первая проверка

- у карточки в Архиве нажмите **«В обзор»**;
- откройте слева **«Редактор обзора»**;
- убедитесь, что отображается исходный полный текст (для новых Contract 0.2 bundle);
- измените редакционный текст и порядок материалов;
- нажмите **«Экспортировать DOCX»**, выберите путь и откройте полученный Word-файл;
- после каждого материала должна быть кликабельная гиперссылка;
- на странице **«Источники»** проверьте независимый переключатель периода.
