# Monitor 0.6.1 — Full-text network + report badge corrective

Установить поверх рабочей 0.6.1 с заменой файлов и пересобрать Windows x64.

Исправления:
- при сетевой/TLS ошибке встроенного HTTP-клиента полнотекстовая догрузка на Windows повторяет запрос через системный `curl.exe` с редиректами, browser UA, Accept-Language и сжатием;
- ошибки догрузки показываются с именем источника;
- после успешного экспорта DOCX красный счетчик у «Редактора обзора» гаснет, но подборка остается;
- любое последующее изменение подборки, порядка, даты или текста снова включает счетчик.

SQLite schema не меняется. SE-monitor не меняется.
