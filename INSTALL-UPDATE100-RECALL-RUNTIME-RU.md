# SE-monitor — Recall & Runtime 0.2.1

## Что делает пакет

* ускоряет предсемантическую дедупликацию без ослабления критериев;
* исправляет распознавание «Китая» и не считает иностранный рынок основанием отклонить явно белорусский региональный материал;
* приводит типографику цитат Groq к одному виду при проверке доказательства;
* добавляет три защищённых профиля для социального жилья, доступной среды после травмы и повторяемого погодного ущерба с публичной ответственностью;
* отсекает международный протокол, будущие правила без текущего вреда и частные жилищные истории без массовости/действия органа.

Groq-контекст, текущий безопасный лимит запроса, резерв ответа и параметры батчинга этот пакет не меняет.

## Установка в GitHub Web UI

1. Распакуйте архив на компьютере.
2. В репозитории замените файлы из архива, сохранив пути:
   * `social_monitor.py`;
   * `ml/groq_semantic_gate/gate_core.py`.
3. В `config/settings.yaml`, в блоке `semantic_gate:`, замените только значения:

   ```yaml
   max_keep: 20
   max_reject: 20
   ```

   `batch_size`, `max_chars`, `batch_request_token_limit`, `max_completion_tokens` и остальные строки не меняйте.
4. Добавьте файл `tests/test_update100_recall_runtime_precision.py`.
5. Commit changes. Обычный следующий запуск применит изменения; dry-run по-прежнему не вызывает Groq.

## Ожидаемый эффект

Ускорение возникает до обращения к Groq: полное сравнение текстов теперь выполняется только внутри одинакового маршрута и событийного отпечатка. При масштабе прогона №70 это устраняет основной квадратичный участок, который съел приблизительно десять минут.

Изменение `20/20` — это не рост общего потолка: максимум остаётся 40 карточек, но очередь становится более сбалансированной — меньше VETO и больше кандидатов на RESCUE.

## Проверка

```bash
python -m pytest -q tests/test_update99_presemantic_dedup_and_adaptive_context.py tests/test_update100_recall_runtime_precision.py
python -m pytest -q
```

Во втором запуске допустимо, что VETO-кандидатов будет меньше 20: это верхняя граница, а не обязательное число.
