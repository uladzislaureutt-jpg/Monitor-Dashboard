# Monitor 0.6.6 — интерактивная 3D-динамика тем

Устанавливается поверх версии 0.6.5.

1. Распакуйте архив в корень репозитория `Monitor-Dashboard`, подтвердив замену файлов.
2. Закоммитьте изменения и отправьте их в ветку, из которой собирается Windows-версия.
3. Запустите штатную GitHub Actions-сборку Windows x64 и установите получившийся `.msi` или `.exe` поверх приложения.

В `package.json` добавлены `echarts` и `echarts-gl`; штатная команда `npm install` в сборке установит их автоматически. Никаких ключей, Supabase-настроек и изменений в SE-monitor пакет не содержит.

## Как пользоваться

На панели **«Динамика публикаций»** выберите **«Темы · 3D»**. График можно вращать мышью и масштабировать колесом. Цветные столбцы — ведущие темы; полупрозрачная золотистая плоскость показывает среднее значение по ячейкам выбранного периода.

Наведите указатель на столбец, чтобы увидеть дату, тему и число публикаций. Щёлкните по нему — под графиком откроются до восьми исходных карточек именно из этой темы и этого дня (или месяца при просмотре периода свыше 90 дней).
