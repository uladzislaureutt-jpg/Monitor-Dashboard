# Monitor 0.6.8 — устранение перекрытия карточек

Устанавливается поверх версии 0.6.7.

1. Распакуйте архив в корень репозитория `Monitor-Dashboard`, подтвердив замену файлов.
2. Закоммитьте изменения и отправьте их в ветку, из которой собирается Windows-версия.
3. Запустите штатную GitHub Actions-сборку Windows x64 и установите получившийся `.msi` или `.exe` поверх приложения.

Исправление отключает только стандартную подсказку ECharts с датой, темой и числом публикаций. Она дублировала содержание карточек и перекрывала их. При наведении теперь отображается только окно с публикациями; полный список по щелчку сохранён.
