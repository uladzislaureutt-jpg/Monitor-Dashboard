# Monitor 0.6.1 — Report Workspace UX corrective

Установить поверх актуальной Monitor 0.6.1 с full-text/network/Edge corrective.

Заменяются только файлы интерфейса:
- `src/reportWorkspace.tsx`
- `src/views/ReportView.tsx`
- `src/types.ts`
- `src/styles.css`

Что меняется:
- общий этап «Подтвердить выбор и получить полные тексты» удалён из рабочего сценария;
- Report Workspace сразу показывает статус исходного текста по каждой выбранной публикации: `полный`, `частичный`, `отсутствует`;
- Contract 0.2 quality учитывается напрямую: `partial` больше не маскируется как `full`;
- старые сохранённые карточки с прежним `excerpt` автоматически трактуются как `missing`;
- для `partial/missing` доступны «Открыть оригинал» и ручная вставка полного текста;
- вручную вставленный текст хранится в рабочей подборке и не изменяет архив/исходную базу;
- красный счётчик у «Редактора обзора» сохраняет прежнюю семантику: показывает только неэкспортированные изменения и гаснет после успешного DOCX.

SQLite schema не меняется. SE-monitor этим пакетом не затрагивается.
