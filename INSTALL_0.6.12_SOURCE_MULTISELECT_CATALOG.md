# Monitor 0.6.12 — несколько источников и актуальный каталог

Накладывайте пакет поверх установленной версии 0.6.10.

1. Распакуйте архив в корень репозитория `Monitor-Dashboard`, разрешив замену файлов.
2. Зафиксируйте изменения в репозитории.
3. Запустите `Build Monitor Dashboard Windows x64`.
4. Установите полученный `.exe` поверх текущего приложения.
5. В приложении выполните обычный импорт или синхронизацию свежего production-артефакта `SE-monitor`.

Что изменится:

- в фильтре «Источник» раздела «Публикации» можно отметить один или несколько источников;
- есть поиск, «Выбрать все» и «Снять все»;
- каталог «Источники» показывает состав из coverage последнего production-запуска мониторинга, а не все исторические записи локальной базы;
- если production-запуска ещё нет, используется последний импортированный запуск;
- снятые из конфигурации источники, например «Ганцавіцкі час», исчезнут из каталога после импорта свежего артефакта;
- публикации снятых источников не удаляются и остаются доступными в архиве.

Supabase, AI-компрессия, настройки `SE-monitor` и существующие данные SQLite не меняются.
