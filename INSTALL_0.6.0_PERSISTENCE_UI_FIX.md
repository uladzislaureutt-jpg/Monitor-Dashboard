# Monitor 0.6.0 — cumulative persistence + dashboard UI fix

Устанавливается поверх Monitor 0.6.0 с заменой файлов. Затем запустите Windows x64 build.

Пакет включает предыдущий Persistence Fix и дополнительно:
- отдельный период 1/7/30/365/всё время для верхней KPI-сводки;
- номер последнего запуска убран из верхней панели (он остаётся на странице «Данные»);
- для SEP-Monitor блок «Персоналии и понятия» заменён на «Резонансные сюжеты»;
- при наличии cross-media/echo данных показываются материалы, освещённые несколькими СМИ; если таких нет — до 4 материалов с максимальным score релевантности.

SQLite schema остаётся 6. SE-monitor менять не нужно.
