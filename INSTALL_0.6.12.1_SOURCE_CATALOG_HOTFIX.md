# Monitor 0.6.12.1 — исправление сборки

Этот пакет исправляет 0.6.12. Накладывайте его на репозиторий, в который уже были загружены файлы предыдущего пакета.

1. Распакуйте архив в корень `Monitor-Dashboard`, разрешив замену файлов.
2. Зафиксируйте изменения в репозитории.
3. Повторно запустите `Build Monitor Dashboard Windows x64`.

Пакет восстанавливает совместимые с версией 0.6.10 файлы 3D-графика и одновременно сохраняет:

- множественный выбор источников в архиве;
- актуальный каталог источников по coverage последнего production-запуска.

Причина предыдущей ошибки: 0.6.12 содержал более старые общие файлы `api.ts` и `i18n.tsx`, из-за чего сборка не находила методы и подписи «Темы · 3D». В этой версии они восстановлены и объединены с новым фильтром.
