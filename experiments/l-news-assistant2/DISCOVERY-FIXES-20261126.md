# Реализация расширения помощника 2 · 26 ноября 2026

Основание: согласованные предложения [USAGE-20261126.md](USAGE-20261126.md). Продолжение после настройки суточного бюджета Cloro 36; лимиты и ротация Cloro в этой работе не менялись.

## Рабочие изменения

- Currents планирует каждое значимое локальное написание независимо от результатов другого написания; добавлены `Łukaszenko`, `لوكاشنكو`, `Lukašenką`.
- `news` и `articles` — отдельные направления с общими расходными пределами и общим индексом повторов. Дополнительный класс включён для девяти выбранных в плане языков: en/de/pl/fr/it/es/tr/uk/cs. Языковые переключатели и страны конкретного сбора ограничивают оба класса.
- Первые написания новостей проверяются по всем выбранным языкам, затем первые написания articles, затем следующие написания обоих классов. Планирование не зависит от пустого/непустого предыдущего ответа. Небольшой разовый бюджет обрезает общий план, а не бюджет каждого класса отдельно.
- The News API продолжает просмотр известного остатка после второй страницы, максимум 8 страниц; неполная страница или достижение `meta.found` завершают направление. При отсутствии `meta.found` полные страницы могут продолжаться до установленного потолка.
- Группа с числом совпадений выше вместимости 8 страниц может разделяться на части до 10 доменов одной страны. Полное множество доменов сохраняется; более слабые приоритетные страны идут раньше UA/RU. Если все дочерние задания не помещаются в оставшийся разовый бюджет, продолжается родительская пагинация.
- Для насыщенной группы до 10 доменов доступны два уровня деления времени. Ни один интервал не выходит за исходные границы; подмена даты вне окна отклоняется до резервирования расхода. Повторы на общей границе исключаются общим индексом.
- Существующий RPC атомарного резервирования расходов не менялся: разовый, суточный, скользящий месячный пределы и резерв аккаунта применяются ко всем новым направлениям. Журнал содержит класс/написание Currents и подгруппу/окно The News API.

|---|---:|---:|
| Currents на сбор / сутки / 30 дней | 64 / 120 / 3 600 | 120 / 200 / 6 000 |
| Currents резерв / страниц | 25 / 5 | 25 / 5 |
| The News API на сбор / сутки / 30 дней | 40 / 80 / 2 400 | 70 / 90 / 2 700 |
| The News API резерв / страниц | 10 / 3 | 10 / 8 |

Миграция меняет старые стандартные значения полей и SQL defaults; другие значения сохраняет. Расписание 19:07 по Минску, окно 26 часов, каталог и правила принятия карточек остаются действующими. Код клиента не менялся; установка новой версии Monitor не требуется. Коллектор развёрнут как v50 с сохранением существующей авторизации.
