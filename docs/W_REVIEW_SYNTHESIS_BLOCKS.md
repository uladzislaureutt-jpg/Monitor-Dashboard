# W-Review: единый план итогового синтеза (18 октября 2026)

Серверное обновление поверх Monitor 0.8.67. Клиентский API и сохранённое досье v3 совместимы; переустановка, повторный анализ и загрузка образцов не нужны.

Проблема: распределение знаков между сюжетами и независимый минимум длины каждого абзаца противоречили короткому зачину, завершению и авторскому ритму.

Изменения:
- Один программно собранный план задаёт бюджеты сюжетов и веток, а также ориентиры абзацев по авторской медиане. Убраны независимые общие минимум/максимум числа абзацев и минимум длины абзаца.
- Рядом с ветками находятся краткие формулировки их доказательств с источниками и ID. Полные карточки сохраняются в запросе. Дословные повторы формулировок не увеличивают фактологическую часть веса ветки; это не семантическая дедупликация.
- В одном ответе GPT-OSS-120B возвращает blocks: opening, выбранные line_N, ending. Сервер соединяет paragraphs в существующее review_text, без технических заголовков.
- Недобор блока ниже 80% плана вызывает предупреждение; отсутствие, повтор/неизвестный ID и нарушение порядка также отмечаются. Общий допуск остаётся ±5%. Предупреждения не означают семантическую проверку полноты.
- Текст сохраняется даже при нарушениях. Старый формат paragraphs/review_text принимается с предупреждением о невозможности измерить блоки. Дополнительного ИИ-аудита, дописывания и повторной генерации нет. Резервы провайдеров прежние.

Проверки: поведенческие тесты бюджетов 1000–8000 знаков, разных авторских медиан, выбранных сюжетов, коротких связок, недобора, отсутствующих/повторённых блоков и совместимости; существующие backend-тесты и строгая TypeScript-проверка. Улучшение реального текста и частоту попадания в объём следует оценить на следующей генерации пользователя.
