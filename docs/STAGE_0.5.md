# Stage 0.5 — Network Workroom

Цель: небольшой общий канал для 5–7 пользователей без переноса архива мониторинга в облако.

Реализовано:

- email/password authentication через Supabase Auth;
- RLS-защищённые сообщения Postgres;
- заметки и закрепляемые объявления;
- автор, время, удаление своих сообщений и администраторское удаление;
- polling каждые 20 секунд;
- локальный кэш ленты при отсутствии сети;
- индикатор непрочитанных в левой навигации;
- «Обсудить» у публикации: в комнату передаются только заголовок и URL;
- миграция локальных заметок 0.4.x по одной;
- RU/BE интерфейс сетевой комнаты;
- более читаемые подписи географического treemap: без белой тени, адаптивный светлый/тёмный текст.

Не входит в 0.5:

- загрузка файлов в чат;
- голос/видео;
- публичная регистрация;
- синхронизация самой SQLite через backend;
- несколько независимых организаций в одном Supabase-проекте.
