# Stage 0.4 — Dashboard / Archive / Search

0.4 превращает Desktop Core из технического импортера в рабочее приложение.

## UX

Главный экран: Dashboard.

Глобальная строка поиска закреплена в верхней панели. `Ctrl+K` переводит фокус в поиск. Первые результаты показываются поверх текущего экрана; полный результат можно открыть в Архиве.

Панель «Команда» выдвигается справа и не занимает место в обычном режиме или при демонстрации Dashboard.

## Data scope

Dashboard и Архив работают с уникальными `monitor_items`/`documents`, поэтому один материал не умножается при перекрывающихся 36-часовых run-окнах.

Период фильтруется по `documents.published_at`. Поэтому материал без определённой даты присутствует в «Всё время», но не входит в 1/7/30/365-дневные срезы.

География графиков — только `events.event_region` / `events.event_locality`, то есть география события, не источника.

## Search scope

Поиск 0.4 охватывает:

- title;
- excerpt;
- canonical source name;
- category / subcategory;
- matched_terms;
- event_region / event_locality;
- event_object / event_problem.

Полнотекстовый индекс FTS5 пока не добавлялся. На текущем масштабе используется SQLite LIKE; при накоплении десятков тысяч документов можно перейти на FTS5 без изменения интерфейса.
