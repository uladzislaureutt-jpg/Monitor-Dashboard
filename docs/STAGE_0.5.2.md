# Stage 0.5.2 — Source Intelligence & Entity Integrity

Этот этап закрывает пункты 3–4 текущей дорожной карты Desktop Core.

## Реализовано

- ranked «Персоналии и понятия» остаются на Dashboard, но персоналии проходят более строгий precision-first фильтр;
- источники, географические названия и типичные названия организаций/редакций исключаются из персоналий;
- кандидат в персоналии учитывается не более одного раза на документ и показывается только при наличии минимум двух разных документов;
- в «Аналитике» добавлена концентрация/разнообразие источников;
- показываются доля лидирующего источника, доля top-5, effective source count и индекс `100 × (1 − HHI)`;
- добавлена сводка здоровья coverage по последнему production-run: stable / recovery / limited / attention;
- low-level ошибки не становятся headline KPI Dashboard.

1. `entities.jsonl`: сущности должны приходить из контракта мониторинга, а desktop перестаёт извлекать персоналии эвристикой.
2. Подготовка второго модуля приложения поверх общего Desktop Core и переключателя модулей.
