# Monitor 0.6.9 — 3D-плоскости тем

Устанавливается поверх версии 0.6.8.

1. Распакуйте архив в корень репозитория `Monitor-Dashboard`, подтвердив замену файлов.
2. Закоммитьте изменения и отправьте их в ветку, из которой собирается Windows-версия.
3. Запустите штатную GitHub Actions-сборку Windows x64 и установите получившийся `.msi` или `.exe` поверх приложения.

В режиме **«Темы · 3D»** вместо столбцов теперь отображаются четыре вертикальные цветные плоскости. В каждой плоскости есть полупрозрачное заполнение, яркая линия и точки конкретных дней. Плоскости разнесены по глубине и поворачиваются вместе с графиком. Карточки публикаций показываются при наведении на точку; полный список остаётся по щелчку.

Фон блока — акцентный сине-зелёный, а палитра тем: синий, оранжево-красный, изумрудный и фиолетовый. Полупрозрачная золотистая горизонтальная плоскость сохраняет значение среднего уровня.
