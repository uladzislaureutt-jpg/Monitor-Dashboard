# Установка 0.4.2 поверх 0.4.1 через браузер GitHub

Используйте пакет `Monitor-0.4.2-update.zip`.

1. Распакуйте ZIP локально.
2. Загрузите его содержимое в **корень существующего репозитория** с заменой одноимённых файлов.
3. Новый файл `src/i18n.tsx` должен быть добавлен в репозиторий.
4. Пакет обновления не содержит `.github`, поэтому рабочий workflow сборки не заменяется.
5. Сделайте commit.
6. Запустите `Actions → Build Monitor Dashboard Windows x64 → Run workflow`.
7. Установите новый NSIS `.exe` поверх существующей версии.

SQLite и уже импортированные runs сохраняются.
