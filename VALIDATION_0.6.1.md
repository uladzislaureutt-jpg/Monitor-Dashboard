# Validation — Monitor 0.6.1

Проверено при подготовке пакета:

- TypeScript/TSX синтаксис проходит `tsc --noEmit --noCheck`;
- RU/BE словари сохраняют одинаковый набор ключей;
- `ReportProvider` хранит максимум 8 выбранных материалов и дублирует состояние в SQLite-backed `app_settings`;
- Report Workspace использует `full_text` из Contract 0.2 и fallback на `excerpt` для старых материалов;
- DOCX-макет отдельно воспроизведён и отрендерен LibreOffice: A4, поля 2.25/1.25/2.0/2.25 см, Times New Roman 16 pt, центрированный заголовок/дата, абзац 1.25 см, кликабельная ссылка после материала;
- Rust-экспорт использует существующую зависимость `zip 8.6.0` и `SimpleFileOptions`, без новых crates;
- страница Источники сохраняет весь каталог, а агрегаты/последние статусы фильтруются по выбранному периоду;
- SQLite schema остаётся 6; существующие публикации, модерация, Workroom и Auto Sync не мигрируются повторно.

Финальный `cargo`/Windows build должен подтвердить GitHub Actions, поскольку Rust toolchain в среде подготовки пакета отсутствует.
