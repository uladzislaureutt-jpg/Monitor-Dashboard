# Monitor 0.6.7 — карточки при наведении на 3D-график

Устанавливается поверх версии 0.6.6.

1. Распакуйте архив в корень репозитория `Monitor-Dashboard`, подтвердив замену файлов.
2. Закоммитьте изменения и отправьте их в ветку, из которой собирается Windows-версия.
3. Запустите штатную GitHub Actions-сборку Windows x64 и установите получившийся `.msi` или `.exe` поверх приложения.

В режиме **«Темы · 3D»** после короткой задержки при наведении на ненулевой столбец появляется компактное окно с тремя публикациями из этого столбца. Данные кэшируются на время открытого экрана. Щелчок по столбцу по-прежнему открывает полный список материалов ниже графика.
