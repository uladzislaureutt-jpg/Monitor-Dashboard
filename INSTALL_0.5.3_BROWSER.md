# Monitor 0.5.3 — установка поверх 0.5.2 через браузер GitHub

1. Сначала убедитесь, что в `Monitor-Dashboard` уже установлена версия 0.5.2.
2. Распакуйте `Monitor-0.5.3-update.zip`.
3. Загрузите содержимое архива в корень репозитория `Monitor-Dashboard` с заменой одноимённых файлов.
4. Сделайте commit.
5. Запустите `Actions → Build Monitor Dashboard Windows x64 → Run workflow`.
6. Скачайте новый artifact и установите NSIS `.exe` поверх существующей версии.

Локальную SQLite удалять не нужно: при первом запуске она автоматически получит migration `0004_moderation.sql` и schema version 4.

## Supabase

Для уже настроенного проекта `monitor-workroom` серверная миграция 0.5.3 применена заранее. Ничего выполнять вручную не нужно.

Для другого/нового Supabase-проекта используйте:
- `backend/supabase/workroom.sql` — полная схема;
- `backend/supabase/upgrade_0_5_3.sql` — только обновление существующего Workroom.

## Поведение модерации

Красный флажок — это не окончательное удаление. Он временно исключает публикацию из аналитики, но оставляет её видимой для проверки. Окончательное решение принимает администратор: «Оставить» или «Удалить».
